# 4x4x4 Cooperative 3D Tic-Tac-Toe

在一个 4x4x4 的三维棋盘上共有 64 个格子。玩家轮流在空格中放置 X 和 O，直到所有格子均被填满。最终状态的评价只取决于标准 4x4x4 三维井字棋中所有完整直线的总数：任意一条长度为 4、且所有格子符号相同的轴向线、棋盘平面内对角线或立方体体对角线，都计为一条完整直线；X 线和 O 线均计入。标准获胜线集合共 76 条（48 条轴向线、24 条平面对角线、4 条体对角线）。求解一个合作博弈最终状态，使棋盘上的完整直线总数最小。

建模时将每个格子的最终符号作为二元决策变量。轮流放置意味着最终恰有 32 个 X 和 32 个 O；由于双方合作，轮流顺序本身不影响最终可行集合。对每一条 4 格直线，设置一个二元变量表示其是否被 X 或 O 完整占据，并最小化这些完整线指示变量之和。

目标是给出全局最优的 4x4x4 棋盘填充、完整直线数量、求解状态和独立验证证据。
