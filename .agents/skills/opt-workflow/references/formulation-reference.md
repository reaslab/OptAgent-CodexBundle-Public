# 数学建模参考

这份参考按可观察的数学结构给出可选表达、所需条件和结果解释。它帮助选择和核验模型，不替题面补数据，也不表示某个理论模型族已由当前执行接口支持。

设原问题的可行域为 $X$，业务目标为 $F(x)$，模型变量为 $z$，模型可行域为 $Z$，从模型解恢复业务方案的映射为 $x=R(z)$。采用任何重写时，都应说清楚它与 $(X,F)$ 的关系：可行域是否双向对应、是否只保留最优值、是否提供原题有效界，或只是近似。需要提交的业务变量、目标单位、遗漏常数和恢复步骤都属于这个关系的一部分。

<a id="f01"></a>
## F01. 题意、变量域与单位

**何时用。** 把文字或数据转成模型时，先区分已给事实、集合与索引、决策、输入参数和临时假设。每个变量需说明索引、取值域和物理单位；每条约束说明量词、时间点、方向、重复计数和允许例外。未定义的输入应保留为待澄清量或显式条件，不能从常见做法或随机种子推造数值。

**表示。** 用集合和参数表达题意，例如按对象集合 $I$、时期集合 $T$ 定义 $x_{it}$，并逐行表示容量、需求、流转和逻辑关系。约束可比较的项应量纲一致；距离、时间、数量和金额之间须使用题面给定或明确声明的换算关系。

需求通常限制销售量、服务量或缺货量，并不单独推出生产量上界。只有在无库存结转、无处置或损耗、无其他用途，且产量与当期需求按题意直接绑定等条件都成立时，才可从需求推得生产上界；否则必须保留库存、处置或用途变量，或不加该界。

**恢复与边界。** 变量定义本身不证明模型忠实。若原始来源只给关系而没给某系数，结果应保留为该参数的条件函数，明确条件和未决项。把一个缺失量取成惯例值会把条件结果变成未授权的特定实例。

## F02. 等价变换、消元、目标常数与缩放

**适用条件。** 代数标准化、变量替换、消元、加辅助变量和单位缩放，都可以帮助求解；它们只有在变量域、约束、目标和输出一并变换时才保留原问题。

**变换。** 对仿射等式 $Ax=b$，若解集非空，可写成 $x=x_0+Bz$，其中列向量 $B$ 张成零空间。把它代入目标和所有约束，得到降低维度的表示。对整数问题，实数仿射参数化还不够：参数必须覆盖原整数解对应的格点。一个充分的简单消元条件是从整数等式中解出系数为 $+1$ 或 $-1$ 的变量；当右端、其余系数及保留变量均为整数时，恢复变量仍为整数。系数不是单位整数时，必须保留整除/同余条件，不能只要求剩余变量为整数。单纯形约束 $\sum_j y_j=1$ 中，可选一个 $k$ 并以 $y_k=1-\sum_{j\ne k}y_j$ 消去单位系数的 one-hot 变量；当右端与保留变量为整数时，恢复值为整数。仍要代回 $0\le y_k\le1$ 界、其他侧约束、目标和输出定义。

**目标映射。** 将模型目标 $f(z)$ 与业务目标之间写成明确关系，如 $F(R(z))=\alpha f(z)+\beta$。当最小化且 $\alpha>0$ 时，最优解排序不变；报告业务目标时仍须还原 $\alpha,\beta$。若 $\alpha<0$，必须同时翻转最小化/最大化方向和界方向。遗漏的加法常数不改变 argmin，却会改变业务目标值以及按业务值计算的相对 gap。$\alpha$ 与 $\beta$ 的单位应使等式两边同量纲。

**边界。** 变量、行或目标缩放应可逆，且逆映射清楚。负数乘不等式要反向；缩放整数变量时要变换其格点，不可把整数域变成任意连续区间。消元和标准形式转换有时会增密或扩大系数，变量减少本身不等于更快。

## F03. 辅助变量、函数图像、逻辑与乘积

**Epigraph 与 hypograph。** 对最小化 $\max_i f_i(x)$，加变量 $t$ 和约束 $t\ge f_i(x)$，目标最小化 $t$，精确保留最优值及 $x$ 的最优解；最优时 $t$ 被压到最大分量。对最大化 $\min_i f_i(x)$，用 $t\le f_i(x)$ 并最大化 $t$。若 $t$ 没有在相应方向上受目标或其他绑定关系压紧，这些不等式只给 epigraph/hypograph，不等于函数图像。凸分段线性函数作最小化目标时可用各仿射段的 epigraph；这表示同一函数值。若要在其他目标方向或非目标项中强制函数图像，需采用能绑定分段选择的精确表示；用切线/弦作外包或内包时应标明它是界还是近似。若 $f$ 是适当闭凸函数、激活域 $X$ 闭凸，且关闭成本为 $c_0$，则 on/off 激活分支 $y>0$ 可用闭透视 $t\ge y f(x/y)+(1-y)c_0$、$x\in yX$；令 $0\le y\le1$ 得到相应凸松弛。整数关闭分支仍须显式满足 $x=0$。$X$ 有界时该式给出相应析取凸包；$X$ 无界时闭透视在 $y=0$ 可能含非零 recession 方向，只能称闭松弛并核对是否符合 $x=0$ 的关闭语义。绝对值 $u\ge x,\ u\ge-x$ 在最小化 $u$ 时会取 $|x|$；若目标不压紧 $u$，需另加精确关系。

**有界完整线性析取与分支仿射成本/资源。** 若源语义确为恰选一分支，且每支为具有有限有效界 $L_k\le q\le U_k$ 并满足 $A_kq\le b_k$ 的有界线性集，令 $\delta_k\in\{0,1\}$ 并为共享向量 $q$ 在各支引入副本 $q_k$：
$$\sum_k\delta_k=1,\qquad q=\sum_kq_k,\qquad L_k\delta_k\le q_k\le U_k\delta_k,\qquad A_kq_k\le b_k\delta_k.$$
若所选支的仿射成本、资源分别为 $f_k+c_k^\top q$、$h_k+H_kq$，应汇总为 $C=\sum_k(f_k\delta_k+c_k^\top q_k)$、$R=\sum_k(h_k\delta_k+H_kq_k)$，再按源保留外部预算及其他全局耦合；完整共享向量及每支全部行都由同一选择变量控制。对连续 $q$，将 $\delta_k$ 放松为 $0\le\delta_k\le1$ 后，该扩展式的投影才是这个局部有界分支并集的凸包；若源中 $q$ 有整数域，仍须保留其整数性，不能把连续分支凸包称为原整数模型的凸包。跨期选择的索引范围由源决定；仅有 one-hot 不会自动抵消放在外层的未选分支系数，逐块凸化也不等于整个联立模型的完整凸包。若源义为若干条件须同时满足，不得改成恰选一。

**二元乘积。** 若 $y\in\{0,1\}$、$L\le x\le U$ 且要令 $z=xy$，有限有效界下可用
$z\ge Ly,\ z\le Uy,\ z\ge x-U(1-y),\ z\le x-L(1-y)$。
分别代入 $y=0$ 与 $y=1$ 可核实其精确性，包括 $L<0$。两个有界连续变量乘积的 McCormick 四面体通常只是有限矩形域上的凸包松弛，不会强制乘积相等。$L,U$ 必须覆盖原可行域，过紧会删解，过松会削弱界。

**Indicator 与 Big-M。** 若语义仅为 $y=1\Rightarrow a^\top x\le b$，且 inactive 域 $D$ 上 $S=\sup_{x\in D}(a^\top x-b)$ 有限，则任何 $M\ge\max(0,S)$ 使 $a^\top x\le b+M(1-y)$ 精确表达该单向蕴含。由有效单变量界计算的区间上界可用，忽略耦合通常使其偏松；完整 inactive 域中的耦合约束可进一步收紧。随手取极大值可能数值弱。该式不表示反向蕴含。若 $S$ 未知或无界，不能宣称存在有效有限 $M$。半连续域 $x\in\{0\}\cup[L,U]$ 可在 $0\notin[L,U]$ 时由二元 $y$ 与 $Ly\le x\le Uy$ 表示；相邻段 SOS、indicator 等也各有明确变量/次序语义，必须匹配具体问题与当前后端接口。SOS1 表示至多一个非零项，SOS2 表示按给定顺序至多两个相邻非零项；使用相应 API 时要核实权重排序和当前后端实现，性能仍需实测。

**已选集合上的最大值。** 对非空已选集合上的最大值，令 $x_e\in\{0,1\}$，其激活义务为 $x_e=1\Rightarrow t\ge c_e$。若有限 $L$ 是 $t$ 的有效下界，可用
$$t\ge c_e-\max(0,c_e-L)(1-x_e)$$
放松未选分支；$t\ge c_ex_e$ 在 $x_e=0$ 时仍强制 $t\ge0$，对允许负目标值的原题未必等价。空选集时函数值另按源定义处理。该构造保留已选项的 epigraph 关系，不要求必须使用某种特定建模接口。

**锥表示。** 例如 $\|u\|_2\le t$ 可写成二阶锥成员关系，但要同时保留 $t\ge0$ 与向量/仿射域；旋转锥变换须按接口约定核对系数和域。某个解析式被 DCP 或 adapter 拒绝，不等于不存在等价锥表示。

**恢复与单位。** 辅助目标变量应使用与其代表业务量相同的单位；乘积变量单位为因子单位之积。提交时从原变量重算业务值。native/indicator 与线性化若定义相同，可在数学上等价，但接口参数或执行支持不能靠名称推断。

完整 Pyomo GDP 教学模型（含构造、`gdp.hull` 变换和手动解恢复）见 [gdp-hull-example.py](gdp-hull-example.py)。恢复函数不是 Core 执行钩子；恢复值仍须由调用者按源问题独立核验。

## F04. 覆盖、调度、流与路径

**覆盖类。** 对有限且完整的候选集合，二元选择变量 $y_j$ 可用 $\sum_{j:i\in S_j}y_j\ge1$ 表示每个元素至少覆盖一次；改为 $=1$ 表示恰覆盖，改为 $\le1$ 表示至多覆盖。标准最小集合覆盖另需目标 $\min\sum_j c_jy_j$。若候选缺失、成本/配额/冲突或服务次数语义不同，该式不再完整；只有覆盖行时，模型可行当且仅当每个元素至少出现在一个候选集合中。将 $\ge1$ 改为 $=1$ 会排除重复覆盖原本允许的解。

**可服务容量与实际分配。** 设选项$x_o\in\{0,1\}$，需求$d_r\in\mathbb Z_{\ge0}$；选项$o$对每项需求$r$有独立服务容量$c_{or}\in\mathbb Z_{\ge0}$，未列关系取$c_{or}=0$。实际服务$y_{or}\in\mathbb Z_{\ge0}$满足$0\le y_{or}\le c_{or}x_o$及$\sum_o y_{or}=d_r$；选中选项可以不使用某项服务资格。若目标只依赖$x$，保留的其他约束也只依赖$x$，且不存在跨需求共享容量/资源、强制启用服务或其他对$y$的额外约束，则消去$y$后精确等价于$\sum_o c_{or}x_o\ge d_r$（每个$r$）。恢复时对每个$r$独立遍历选中选项，从剩余需求中分配$\min(c_{or},\text{剩余需求})$，直至满足$d_r$；整数容量保证整数分配。单位容量时即选取$d_r$个可服务的已选选项，而非把全部资格都当作实际服务。若存在$\sum_r y_{or}\le C_ox_o$等共享限制、服务费用依赖$y$，或其他分配约束，应保留相应分配变量与耦合，不能只用这些覆盖行替代。

**流与运输。** 有向单商品流变量 $f_{ij}$ 在非源汇节点满足流入等于流出；流值是源点净流出，也等于汇点净流入。单看源点出弧总量只有在没有流入源点等附加条件下才等于净流值。运输等式模型需供需总量平衡，或明确加入虚拟供需/不等式处理不平衡。

若每辆车对每个客户至多访问一次，按车 $k$、客户事件 $i$ 以入弧和出弧各等于服务指示变量表示访问；跨车汇总行再表达客户必须服务或可选服务。度平衡不保证路线连到 depot，也不排除子环。TSP/多车路径需按题意增加适用的连通、容量与子环消除条件；方向、开放/闭合路线、车辆数和回 depot 约束都须与原问题相符。

**无向 required-edge 闭合巡检（条件式 T-join）。** 当目标是以总 traversal cost 最小化一条覆盖每条 required 物理边至少一次的闭合路线，且图无向、每次 traversal 成本非负，required 边非空、其多重子图连通并含 depot，且没有容量、时窗、方向、转向状态或其他路径耦合约束时，以全部允许通行的物理边构成原允许图，并令 $T$ 为 required 多重子图中的奇度顶点；精确最优值为 required 边成本总和加上在原允许图上取 $T$ 的最短路度量闭包后求一般图最小权完美匹配的成本。将匹配边对应的原允许图最短路径补入 required 多重图后，各点度数为偶且支撑连通，可从 depot 取 Euler 闭合 walk 并恢复原物理边。闭包只含 $|T|$ 个点和至多 $|T|(|T|-1)/2$ 对；任一条件不满足时不能直接套用。

**调度。** 两项活动不能重叠时，可用二元次序变量选择“先 $i$ 后 $j$”或反向，并使用覆盖整个 inactive 时间域的有效 $M$；也可用 time-indexed、事件或 interval 表示。必须保留可选任务、机器资格、setup、释放/截止时间、工艺顺序与累计资源容量。NoOverlap 不自动代表一般累计资源约束。

**全幺模与整数性。** 若完整约束矩阵 $A$ 全幺模（每个方阵子式均为 $0,\pm1$），右端为整数，则标准多面体的顶点为整数；整数有限上下界可作为单位行并入。因而在有限最优值能于顶点取得时，存在整数最优顶点；这不表示每个最优点或求解器返回的任意凸组合点都是整数。节点—弧 incidence matrix 是 TU，但添加的业务侧约束也必须检查；多商品耦合、固定费用、TSP 度行不能仅凭“像网络”套用整数性结论。供需、容量、单位与流量须按原单位复核。

<a id="f04-matching"></a>
**瓶颈与稳定匹配。** 对非空、左右等大的一对一指派，若目标是最小化已选边最大成本，令 $E$ 为源定义的合法边集，按有限 distinct cost 的阈值 $\tau$ 建允许图 $\{e\in E:c_e\le\tau\}$；无额外耦合时，最小可完美匹配阈值即最优值。恢复完整双射并核对边资格。额外预算、配额等必须保留在阈值可行性判据中，普通完美匹配不自动充分。缺边与 sentinel 按源 schema 解释，不能自行把零成本当作禁边。

源明确要求稳定、两侧等大且偏好严格完整时，令 $r_i(j)$、$s_j(i)$ 从 1 起，连续变量 $x_{ij}\ge0$ 满足 $\sum_jx_{ij}=1$、$\sum_ix_{ij}=1$，并保留源目标及其方向；仅当源目标确为 egalitarian 名次和时才使用 $\sum_{i,j}(r_i(j)+s_j(i))x_{ij}$。每对的无阻挡条件为
$$x_{ij}+\sum_{j'\succ_i j}x_{ij'}+\sum_{i'\succ_j i}x_{i'j}\ge1.$$
令 $j_i(k)$、$i_j(k)$ 分别为对象 $i$ 与 $j$ 的第 $k$ 名，按各自偏好序设 $P_{i,0}=Q_{j,0}=0$、$P_{i,k}=P_{i,k-1}+x_{i,j_i(k)}$ 且 $Q_{j,k}=Q_{j,k-1}+x_{i_j(k),j}$，并有 $P_{i,n}=Q_{j,n}=1$；稳定行可写为
$$x_{ij}+P_{i,r_i(j)-1}+Q_{j,s_j(i)-1}\ge1,$$
把重复展开的 $O(n^3)$ 非零项缩为 $O(n^2)$。无额外业务侧约束的基础完美稳定匹配多面体有整数顶点，因此线性目标可用 LP；保留 quota、跨 pair 约束等后须重新检查整性，或保留整数变量。恢复时核对完整双射、整数性和全部 blocking pairs，不能盲目舍入，也不能用单侧 Gale–Shapley 代替双侧名次最优。不要求稳定、偏好有 ties、列表不完整或匹配为多对一时，不能直接套用此域与整性结论。

## F05. 合法稀疏化、聚合、支配与对称

**合法索引稀疏化。** 仅对题目/数据明确禁止的组合省略变量，或对已证明恒为零的项删变量。可把省略项按零扩回原索引，再确认所有原约束、总量和输出仍有定义。经验上少见、成本高、当前方案未使用都不等于禁止。稀疏化可以缩小模型，但不单独证明最优值保持。物理边的源成本、容量、required 标记等属性须按稳定原 `edge_id`/索引绑定；平行 required 边是不同业务记录，不能合并。仅在构造 deadhead 最短路距离时，才可把同端点候选边投影为最小成本，并保留实现该最小值的原 `edge_id` 以恢复路径；输出须逐次列出所用原边并按每次 traversal 计费。

**聚合。** 当对象在目标系数、变量域、可行选项以及所有关联约束中完全可互换时，可按共同特征聚合数量。若按类型取总量 $n_g$，目标按单个对象成本乘计数；若以代表变量表示整组，则代表成本需乘组内对象数；整数总量须按原类型可行域取值。保留聚合组到原成员的映射，按原变量域恢复各成员决策，再以原索引核对原题约束与目标；整数总量的恢复须保持整数域。身份、先后、专属配额、公平性或不同输出一旦影响决策，聚合就不再自动等价。

**支配删除。** 只有能证明某列在每种可行组合中都可由另一列替换、覆盖不减少、目标不变差且所有侧约束仍满足时，才能删去被支配列。比如只有覆盖行且各成本非负的纯最小集合覆盖中，若列 $j$ 覆盖集合包含列 $i$ 的覆盖、成本不高于 $i$，且没有其他侧约束区分二者，保留 $j$ 可替换单个 $i$；配额、类别硬约束、分配数量或负成本都可能破坏条件。批量删除时须保证至少保留替代者。

**启用收益/成本的全域支配。** 设基准方案 $x^0$ 在完整原题中可行。若能对每个原题可行方案 $x$ 证明
$$F(x)\le F(x^0)+\sum_i z_i(B_i-C_i),\qquad z_i\in\{0,1\},\quad B_i\le C_i,$$
其中 $z_i$ 表示是否启用对象 $i$，$B_i$ 覆盖启用带来的全部收益，且共享收益与启用成本各计一次，则 $F(x)\le F(x^0)$，所以 $x^0$ 是最大化最优方案。关键是这个不等式必须覆盖整个原可行域；抽样方案或只计算已选局部收益不够。最小化时须另证方向相应的全域下界，使每个原题可行方案的目标不低于基准目标。

**对称性。** 变量置换只有在完整变量域、目标和全部约束下都保持模型时才是真正对称。添加代表选择约束可减少等价排列，但约束合取后必须在每个可行轨道至少留一个代表，并保存恢复标签的方法。若任务要求具体身份、次序或不同成员输出，去掉对称轨道不能丢失这些业务信息。所有这些方法应把原业务目标及单位保留在映射中；结构减少不自动意味着更快。

<a id="f06"></a>
## F06. 等价、松弛、限制、有效强化与近似

设原问题可行域为 $X$，目标相同。以下关系不能混称“等价重构”。

- **双向等价。** 变换后每个可行解可恢复成原题可行解，且每个相关原题解都被表示（或投影后可行域相同）。目标值映射一致，方可把全部最优性结论搬回。
- **原题有效松弛。** 若 $R\supseteq X$，最小化时松弛最优值不高于原题；松弛的 global lower bound 可作原题下界。松弛点未在 $X$ 核验前不是原题可行方案，不能作原题上界。最大化时界方向相反。
- **限制模型。** 若 $H\subseteq X$，最小化时在 $H$ 找到并核验于 $X$ 的方案可作原题上界；限制模型自身的下界不自动成为原题下界。只有证明某原题全局最优解仍在 $H$ 中（或独立证明最优值相等），才可说限制保最优值。它即使保最优值，也未必保留所有原可行解。
- **有效不等式/割。** 需证明它对每个原整数可行解都成立；加入到外部松弛中可切掉分数或违反点，同时保留原整数可行集。覆盖、clique、subtour、capacity 等割各有自己的变量、符号和计数前提；抽样未见反例不是有效性证明。例如 0-1 背包中若 $a_i\ge0$ 且覆盖集 $C$ 满足 $\sum_{i\in C}a_i>b$，则 $\sum_{i\in C}x_i\le|C|-1$ 有效；冲突图中两两互斥的 clique $Q$ 满足 $\sum_{i\in Q}x_i\le1$。TSP 子环割和 CVRP 容量割还需匹配有向/无向弧的计数方式、需求及车辆容量。
- **近似/启发式。** 改变可行域、目标或停止精度时，须说明误差、质量保证或仅作为候选。近似解只有通过原题核验后才能作 incumbent；启发式停止不构成全局最优证明。

恢复每个方案时都重算原题约束和目标。目标常数和单位沿 F02 还原；“restricted bound”“relaxed objective”或 solver status 不能凭同名变量变成原题界。

<a id="f07"></a>
## F07. 对偶、界与最优性证据

**适用条件。** 对标准形式线性规划 $\min c^\top x$，满足 $Ax\ge b,\ x\ge0$，其对偶为 $\max b^\top y$，满足 $A^\top y\le c,\ y\ge0$。若原模型行列数量或稀疏结构明显不平衡，可比较 primal 与 dual 的变量、约束和非零项规模；少变量的那一侧也可能有更密的矩阵。对偶解给界，不是原题业务方案；需要原域可行点时仍须单独恢复/构造 primal 方案。

**证据。** 最小化问题的原可行点给上界，满足对应符号条件的对偶可行解给下界；最大化相反。弱对偶在适用的可行性条件下给出方向性界。数值最优性可由已核原域点与有效 global bound 在同一业务目标、同一实例和相同单位上闭合支持；仅求最优值时，也可经已证等价/强对偶关系转移相应计算表达中适用的数值最优性。强对偶或最优解可恢复还需要适用的可行性、闭凸性/资格条件与达到性，不能把弱对偶写成等号。

**加性收益与共享资源价上界。** 对最大化问题
$$\max\sum_i v_i(x_i)\quad\text{s.t.}\quad\sum_i r_i(x_i)\le B,$$
不等式按资源分量解释。任取 $\lambda\ge0$，若每个 $X_i$ 覆盖原题可行解在局部 $i$ 上的全部选项，则
$$U(\lambda)=\lambda^\top B+\sum_i\sup_{x_i\in X_i}\bigl[v_i(x_i)-\lambda^\top r_i(x_i)\bigr]$$
是原题上界。对任意原题可行 $x$，弱对偶的一行推导为
$$\sum_i v_i(x_i)=\sum_i\bigl[v_i(x_i)-\lambda^\top r_i(x_i)\bigr]+\lambda^\top\sum_i r_i(x_i)\le\lambda^\top B+\sum_i\sup_{x_i\in X_i}\bigl[v_i(x_i)-\lambda^\top r_i(x_i)\bigr]=U(\lambda).$$
各个局部上确界须精确求得，或以已证明的有效上界代替；局部可行值只是下界，不能替代上确界。可以放松其它耦合限制，但放松后的 $X_i$ 仍须覆盖原题每个局部选项；目标/资源贡献的重数与单位须一致，任何共享收益或成本都只计一次。上确界未达到时保留 $\sup$；若某项无上界，则该项为 $+\infty$，此乘子不能给出有限上界。该不等式只用可行性与 $\lambda\ge0$，不要求凹性或强对偶。

Fenchel 共轭可给凸问题对偶；非凸函数的双共轭通常是其闭凸包，不是原函数。拉格朗日松弛一组耦合限制后，对最小化通常给原问题下界并可拆分子问题，但需按原域构造/核验可行点，形成上下界后才可报告 gap。

**目标与单位。** 对偶乘子量纲由对应约束量纲与目标量纲决定；比较 primal/dual 前还原目标常数、缩放和业务单位。近似数值相等要按目标尺度和原模型可行残差解释，求解器状态“optimal”本身不是数学证书。普通可信数值 global bound 可支持结论，不需要为了形式给每个数值题另造解析证明；解析证明可以独立于数值 Run 成立。

<a id="f08"></a>
## F08. 凸性、次梯度、KKT 与变分不等式

**凸优化。** 凸最小化的标准形式包括凸目标、凸不等式子水平集 $f_i(x)\le0$ 和仿射等式；凹目标最大化对应。约束反向时集合通常变非凸。Hessian 半正定仅在二次可微且全定义域验证后支持凸性。DCP 规则是可验证凸性的充分语法，不是所有凸表达式的完整判别。

**KKT 与约束资格。** KKT 包含原可行、对偶可行、stationarity 与互补。对凸问题，若有有限最优值且满足适当约束资格（如常见 Slater 条件），可保证最优乘子/强对偶并使 KKT 成为最优性刻画；Slater 是充分条件而非唯一条件。对非凸可微问题，CQ 通常只使 KKT 成为局部最优的必要一阶条件，不使它充分。CQ 失败意味着通用必要性结论不可用，不等于某个具体最优点一定不满足 KKT。把下层问题直接替换成 KKT，还须证明所需凸性、资格和变量域。

**次梯度与法锥。** 对适当闭凸函数 $f$ 与非空闭凸集 $C$，约束 $x\in C$ 可写作 $f+\delta_C$，其中 $\delta_C$ 在 $C$ 上为零、外部为 $+\infty$；$0\in\partial(f+\delta_C)(x^*)$ 等价于凸最小化最优性。将其拆成 $0\in\partial f(x^*)+N_C(x^*)$ 需次微分和规则，例如有限维下相应相对内部条件 $\operatorname{ri}(\operatorname{dom} f)\cap\operatorname{ri}(C)\ne\varnothing$。不能只因看见两个项就无条件拆和。可微 $f$ 时 $-\nabla f(x^*)\in N_C(x^*)$ 是凸可行集上的几何最优条件。

**变分不等式与势。** VI 为找 $x^*\in K$ 使 $F(x^*)^\top(y-x^*)\ge0$ 对所有 $y\in K$ 成立。只有当 $F=\nabla\phi$ 且 $K$ 凸、$\phi$ 可微凸时，VI 才等价于在 $K$ 上全局最小化 $\phi$。若 $\phi$ 非凸，条件仅为相应的一阶条件；若 $F$ 不是某势函数的梯度场，不能直接宣称它是单目标最小化。互补条件本身常为非凸，互补表达不会自动带来凸性。

恢复时报告原变量、乘子/残差的单位与对应业务含义。数值 KKT 残差只描述所检验表达和尺度，不代替原域可行性或全局界。

<a id="f09"></a>
## F09. 可分离、分解与迭代算法

**可分离。** 若可行域是乘积 $X=X_1\times\cdots\times X_n$ 且目标为 $\sum_i f_i(x_i)$，原问题可逐块精确优化。任何共享容量、预算、逻辑或时序约束都会耦合块；需交给 master、协调变量或对偶，而不能分别求完再无条件拼接。

**Benders 与列生成。** 连续 LP recourse 的 Benders optimality cuts 来自完整可行的子问题对偶点，feasibility cuts 来自相应对偶射线；需处理实际不可行的子问题；声称原题达到所需数值最优性，须由原域可行解与有效全局界在相同目标下闭合。整数 recourse 的有效 LP 松弛所产生的对偶 cuts 仍可给原问题下界，但分数 recourse 点不代表整数原域可行，LP 松弛闭合也不证明整数原题最优。Dantzig–Wolfe/column generation 在完整列空间、正确凸组合结构和精确 pricing 下，直到无负 reduced-cost 列可证明完整 LP 松弛最优；这不等于整数最优。整数结论通常需要 branch-and-price 或另一个完整整数证据。

**ADMM 与近端法。** 两块凸 ADMM 在适用的闭凸性、可解子问题及算法条件下有收敛理论；任意多块顺序更新不能据此断言收敛。prox 是子问题算子，例如投影是到闭凸集的欧氏近端；把目标拆为光滑项与非光滑项并不会一次性解完整体问题。迭代法需满足相应步长/正则条件并报告停止准则。平滑替代通常改变目标，除非有误差界或另行证明精确。

**恢复与证据。** 每次分解都要保留 master 的所有耦合条件，合并子问题解后检查全局约束并恢复业务方案。分解对象、变量/界和目标单位需与原问题一致；如果只证得 LP 松弛或近似停止，就按该范围报告。上述算法知识不表示当前 builder 或 adapter 已提供迭代执行能力。

<a id="f10"></a>
## F10. 不确定性、稳健性与非预见性

**鲁棒模型。** 线性不确定约束 $a(u)^\top x\le b$ 对全部 $u\in U$ 成立时，可写成 $a_0^\top x+\sigma_U(B^\top x)\le b$，其中 $a(u)=a_0+Bu$、$\sigma_U$ 是集合 $U$ 的支持函数。多面体 $U$ 可在适用可行有界与强对偶条件下对偶化为线性式；椭球集合常导出二阶锥式。对应式只对所给的不确定集合准确；换相关性、预算或边界会改变鲁棒性。

**情景随机规划。** 期望目标按真实概率加权。若两情景在某决策时点共享相同已观测历史，则该时点决策必须相同（nonanticipativity）；信息不同之后的补救决策可不同。把所有场景全部决策强制相同会过度限制，提前分开则相当于预知未来。风险度量、情景树、概率和各场景约束都须保留。

**算法边界与恢复。** 情景采样通常只是有限样本近似，不能称对整个不确定集有 robust guarantee。Progressive hedging 是特定结构上的分解算法，通用整数/非凸问题不保证有限步全局最优。输出要恢复每一阶段/场景业务决策并检查共享历史约束；目标权重和概率无量纲，成本值仍按业务单位报告。

<a id="f11"></a>
## F11. 字典序、多目标与软约束

**字典序。** 严格最小化字典序目标先求 $f_1^*$，再在约束 $f_1=f_1^*$ 下优化 $f_2$，然后依次锁定已证明的较高优先级最优值。约束 $f_1\le f_1^*+\epsilon$ 表示允许一级目标容差的优先级，不是精确字典序。有限加权和要保持严格优先，至少要有可证的一级最小正间隔 $\Delta>0$ 及后续目标总变化范围 $R$，并令主权重满足 $W\Delta>R$；连续一级目标通常没有统一正间隔。不同层目标单位须先明确；加权系数需承担对应单位换算，避免把“数值很大”误当优先级证明。每层报告原始目标值及容差。

**软约束与罚项。** 把硬约束 $g(x)\le0$ 改成 $g(x)\le s,\ s\ge0$ 会扩大可行域。只有任务授权违反并且报告违约量、单位与代价时，才能把它当软约束；或者针对具体问题证明罚系数满足 exact-penalty 条件。L1 exact penalty 需要相应正则性且罚系数超过适用乘子界；二次罚一般有限权重仅近似。任意罚值可能偏好违反业务规则的解。

**Slack 与 Phase-I。** 对 $a^\top x\le b$，加非负 slack 可写为 $a^\top x+s=b$ 的精确等价式；对 $a^\top x\ge b$ 用 surplus $s\ge0$ 写为 $a^\top x-s=b$。算法人工变量只用于构造初始基或诊断，不能无代价留在最终业务问题。单边非负人工残差不适用于所有等式/右端符号；Phase-I 最优值为零才支持原式可行。恢复原目标时删除算法变量，并说明目标常数与罚项单位。

<a id="f12"></a>
## F12. 动态规划

**适用条件。** 有限阶段问题若状态包含影响未来成本、可行动作和可行性的全部历史信息，Bellman 递推可精确给出最优值和策略。最小化时按逆向递推 $V_t(s)=\min_{a\in A_t(s)}\{c_t(s,a)+V_{t+1}(T_t(s,a))\}$；最大化问题按相应方向替换，并给定准确终端值。

**恢复与代价。** 保存每个状态的最优动作，再从初态追踪到终态，即可还原完整业务路径。阶段成本和 $V_t$ 必须使用一致的业务单位；目标常数可沿阶段相加，但要只计一次。若状态/动作空间可以精确枚举，递推是精确算法；状态空间过大时近似值函数/离散化需给出误差或作为近似说明。

**失效边界。** 遗漏库存、剩余资源、访问集合或已揭示信息等会让未来可行性不同的状态被错误合并。仅有“多阶段”或“递推形状”不够证明适合 DP；常见运行接口也不自动提供 Bellman 迭代。

<a id="f13"></a>
## F13. 矩阵与张量的低秩表示

**矩阵。** 对一般实矩阵，约束 $\operatorname{rank}(X)\le r$ 非凸。分解 $X=UV^\top$（$U,V$ 各有 $r$ 列）参数化 rank 不超过 $r$ 的矩阵；当 $r$ 低于允许的最大秩时，它是明确的秩限制。因子解需回构 $X$ 并核验原来的观测、业务约束，以及题目确有要求时的正半定条件。因子化有乘积项及非唯一性，通常非凸；即使 $r$ 足以表示所有矩阵，也不因此变成凸模型。

**张量。** CP、Tucker、TT 等不同秩定义对应不同低秩集合；固定小秩会排除超过该秩的对象。展开矩阵核范数常作凸 surrogate，但一般不等价于固定张量秩。

**目标、恢复和边界。** 核范数惩罚或约束的系数应与原目标尺度和单位匹配；将低秩代理改成原始业务值前，需回构完整张量/矩阵并重算原约束与目标。只有在问题结构和额外恢复条件成立时，凸 surrogate 才可证明恢复原低秩解，不能默认精确。

<a id="f14"></a>
## F14. 数值尺度、求解类别与执行接口

**尺度。** 用源定义的变量单位、行范围和目标量级判断数值尺度。若把最小化目标乘以正数 $k$，最优方案不变，primal 目标、dual 界和绝对目标 gap 都乘以 $k$；目标绝对容差也要按 $k$ 换算回原单位。约束可行残差仍按各自行单位解释，最优性/对偶残差和内部归一化规则依实际后端，不能假定同时改善。报告前须按逆映射还原界与 gap。对变量/约束作可逆缩放时也要逆变换解与相关乘子，并在原题单位重算残差、约束与业务目标。

长链递推中，即使矩阵非零系数均为单位量级，自由状态上的很小绝对对偶残差也可能乘上较大状态变化并沿多期累积，影响界与目标核验。因此“系数看起来规整”或求解器状态“optimal”不足以单独排除数值问题。若能从题目定义的变量、约束或成本单位推得正尺度，可将正缩放作为候选数值表示；必须把点、目标、有效界及相应残差按映射还原，并在原题单位核验原域可行性、界方向和业务目标。缩放不保证数值改善或提速，也不能把求解器结果字段本身当作有效界。尺度应由源中自然的距离、时长、容量或成本推导，不应使用任意容差或把缩放单位当成业务单位。

**结构与执行。** 先由完整模型判断 LP、QP、锥、整数、非线性或图结构，再查当前真正接线的求解接口。准确支持边界以仓库 model-authoring 参考中的“后端支持边界”为准；理论上存在算法不代表当前接口可调用。拒绝一个表达式也不单独证明问题非凸，可能存在另一个已证明等价且受支持的表示。

Solver log 中的节点数、界、presolve、系数范围、迭代和终止码是诊断证据，不会唯一确定慢因。Warm start 只是提交/接受求解器初值的接口，不自动保证可行、改善或加速。对偶乘子可在适用的可微/稳定区域解释为局部边际价值；active set 或基变化后不保证延续为全局线性灵敏度。比较方法时保持同一模型范围、目标单位、后端设置和停止准则，分别记录构建、求解、恢复与检查时间；状态、被选中的结果和数学正确性是不同结论。
